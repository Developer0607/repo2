1. 为什么分"活动列表"和"待定池"两个容器

活动列表只放"当前看得见"的目标，绘制时直接画。待定池放"暂时看不见但可能回来"的目标，不参与位置匹配，只参与特征匹配。这样位置匹配不会因为待定目标干扰而错配。
2. 恢复 ID 的判定条件

新目标要恢复成待定池里的旧目标，必须同时满足：

    形状类别一致（圆 vs 非圆，避免圆形和方形混淆）

    面积比例 > 0.5（避免大小完全不同的目标）

    宽高比 > 0.5（避免细长和方正的混淆）

    直方图距离 < histThreshold（颜色分布相似）

四个条件都过了，再按"直方图距离 + 位置距离"综合评分选最优。多重约束能大幅降低误匹配。
3. 位置距离为什么除以 1000

直方图距离在 0~1 范围，位置距离在 0~几百像素范围。直接相加会让位置主导评分。除以 1000 把它压到 0~0.几，让直方图相似度成为主导，位置只做微调。
4. 待定池超时清理

maxLostFrames = 90 表示目标丢失后最多等 90 帧（约 3 秒@30fps）。超过就认为它真的离开了，永久删除。这个值要根据场景调：

    遮挡短（如过柱子）→ 30~60 帧

    遮挡长（如进出画面再回来）→ 120~300 帧

    但太长会增加误匹配风险，因为待定池里目标多了，新目标可能匹配到不相关的旧目标

调参建议
参数	作用	调整方向
histThreshold = 0.35	直方图相似度门限	误匹配多则调小（0.2），找回率低则调大（0.5）
maxLostFrames = 90	待定池保留时长	遮挡久则调大
areaRatioThreshold = 0.5	面积比例下限	目标尺度变化大则调小
maxDist = 80	位置匹配距离	目标移动快则调大
